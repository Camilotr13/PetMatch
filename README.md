
# Pet Adoption App 🐾

A mobile application that connects people who find abandoned pets with users who want to adopt them. The platform helps animals find a new home while creating a community focused on responsible pet adoption.

## Features
- User registration and authentication
- Publish pets available for adoption
- Browse pets looking for a home
- Pet profiles with photos and details
- Contact between adopters and publishers
- Advertising space for pet-related businesses

## Tech Stack
**Frontend**
- React Native
- TypeScript

**Backend**
- Java
- Spring Boot

**Database**
- PostgreSQL

**Tools**
- Postman (API testing)
- DBeaver (database management)
- Git & GitHub (version control)

## Goal
Reduce the number of abandoned pets by making the adoption process easier and connecting people who want to help animals.
